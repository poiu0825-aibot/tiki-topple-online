# 爆破不倒翁

以 Tiki Topple 為規則靈感的 2–4 人瀏覽器遊戲。主要遊玩場景是神社牆前的九色不倒翁塔：玩家可走動、爬 A 字木梯、出牌調整塔的順位，也能射擊或搖晃木梯干擾對手。只有塔頂前三名會為各自的祕密任務得分。boardgame.io 同步房間、回合與玩家位置；Three.js 呈現立體塔與角色。預設網址進入神社立體版，原平面場景保留在 `/?variant=flat`。

## 本機啟動

需要 Node.js 20 或更新版本。

```sh
npm install
npm start
```

開啟 `http://localhost:5173`。`npm start` 會同時啟動 Vite 網頁（5173）、boardgame.io 遊戲伺服器（8000）和 Socket.IO 聊天室（8001）。

房間狀態存在遊戲伺服器記憶體中，伺服器重新啟動後會清除。跨網路分享需要在前端建置時將 `VITE_GAME_SERVER`、`VITE_CHAT_SERVER` 設為公開伺服器網址，並在伺服器設定 `GAME_ORIGIN`。別人的瀏覽器無法連到你電腦上的 `localhost`。

區域網路遊玩時，可把 `GAME_ORIGIN` 設為房主電腦的網頁網址（例如 `http://192.168.1.20:5173`）；頁面會以相同主機名稱連到 8000、8001 埠。網際網路遊玩需將網頁和兩個服務部署到可公開連線的主機。

## 公開部署

`render.yaml` 會將前端、boardgame.io 遊戲伺服器與聊天室部署為同一個 Node.js Web Service。將此 repo 連到 Render 後建立 Blueprint，Render 會依設定建置網站並啟動服務。服務使用 HTTPS 與 WebSocket，房主可分享房間連結給朋友。

免費 Web Service 閒置 15 分鐘後會休眠，下一次連線可能需等待約一分鐘；服務重啟或休眠時，記憶體中的房間會清除。適合朋友測玩，不適合需要持續在線或保存房間資料的正式服務。

## 規則摘要

- 2–4 人一局，九座圖騰由前至後排列。每人抽取三座有高、中、低順位的祕密圖騰。本站每人原有 8 張動作牌（包含新增的「互換」）；每局發牌時，雙人局各隨機移除 1 張、每人保留 7 張，三至四人局各隨機移除 2 張、每人保留 6 張。移除的牌每局重新隨機決定。
- 每回合打出一張牌：上移 1／2／3 將不倒翁往上移；推倒使其落到最下方；互換可交換任意兩座不倒翁；爆破只能炸掉最下方。英文牌面對應 `RAISE`、`DROP`、`SWAP`、`BLAST`。每位玩家的本局首回合不能使用爆破牌。
- 一局在只剩三座圖騰或所有人的手牌都出完時結束。最高順位祕密圖騰在第一名得 9 分；中順位在前兩名得 5 分；低順位在前三名得 2 分。
- 房主設定 1–60 分的整場目標，至少完成一局才判定勝負。玩家入場時由遊戲自動分配不重複的角色顏色，未選頭像時也會隨機分配一款。

## 操作

- 建房後分享網址或配對碼；配對碼可在首頁搜尋。重新開啟房間連結時，瀏覽器會嘗試以本機保存的憑證回到原座位。
- 透過配對碼或邀請連結加入後，每次都會顯示 15 秒姓名與頭像選擇。姓名最多 20 字；未輸入時依現有房間名稱使用「路過玩家1」、「路過玩家2」等。WASD／方向鍵可行走，點地板可移動；拖曳可旋轉並調整視角高度，手機可用雙指縮放。出牌時伺服器依人物當下站立位置選取目標；神社版使用「互換」時，從場上列表依序選兩個頭像，第一個選項會讓角色移到對應高度，再以當下站位確認操作。
- 點其他玩家會自動走過去推擠，對方會跌倒、位移並站起來。接近人頭時玩家頭上的名稱旁會顯示紅色順位數字。
- 九張平面人頭依順位在地板上排列，旁邊標有 1～9。Toast 爆破最後一張人頭，附近玩家會被炸飛；上方人頭及周圍短暫燻黑五秒。
- 祕密任務圖騰以約 60% 不透明度顯示在場景邊緣，可收合。聊天室文字與快捷對話都會在說話者頭上顯示約三秒的半透明泡泡。
- 圓盤上有橫式的玩家總積分板，手牌上方顯示目前排列的即時得分；四角座位姓名標籤已移除。快速對話按鈕位於場景右下角，計分規則與局數同列並可收合。
- 計分規則可收合。每局結算後積分背板閃爍 1 秒，再倒數 3 秒自動進入下一局，總分繼續累計。達到房主設定目標分數時，場景才會詢問玩家 `YES` 留下再玩一場或 `NO` 回首頁；再次開場由第 1 局、0 分開始。

## 本機立體頭像塔試作

已用 Blender MCP 製作九層不倒翁頭像塔，放在原版圓盤旁作對照，可按「近看立體對照塔」調整視角。詳細資產、動畫及擺放判斷見 `docs/daruma-tower-prototype.md`。原平面遊戲已封存於本機的 `versions/2026-09-25-flat-game-before-3d-tower.zip`。

## 專案結構

- `src/game.js`：boardgame.io 規則、局數與分數狀態。
- `src/main.jsx`：首頁、房間、玩家操作與聊天室。
- `src/TikiScene.jsx`：平面圖騰、火柴人、視角、行走與爆破動畫。
- `src/darumaTower.js`：本機立體塔對照顯示與下降動畫。
- `src/tikiArt.js`：地板圖騰與祕密卡共用的人頭 SVG。
- `src/layout.js`：圖騰順位位置、玩家起點與操作距離。
- `src/style.css`：響應式介面、牌組與提示動畫。
- `server/index.js`：boardgame.io 伺服器與 Socket.IO 聊天服務。
# 神社牆面版

公開網站預設網址 `https://tiki-topple-online.onrender.com/` 進入神社牆面版本；本機開發網址為 `http://127.0.0.1:5173/`。原本平面版與第一座立體對照塔保留在 `/?variant=flat`。神社版使用獨立的 `tiki-topple-shrine` 房間，分享連結會帶上 `variant=shrine`；平面版連結會帶上 `variant=flat`。

神社版把九個不倒翁頭像堆在鳥居前的牆面，A 字木梯緊靠頭像塔。點頭像或木梯橫階可選對應高度，玩家名稱與背板也標示順位；點地面或按 WASD 可在場景下方自由移動。任務卡使用相同 Blender 模型渲染的人頭圖。半透明手牌貼在場景下緣，選牌後才顯示右側的「開始行動」；即將得分固定在可收合任務欄的標題旁。「互換」會以一排依順位排列的場上頭像取代手牌，依序選兩個，場景空白處可取消。爆破選牌後可直接按「開始行動」炸掉最下方，不需先爬到該層。射擊與搖晃在快速對話上方直排，並避開落地按鈕。射擊可選梯上玩家，使目標上升一階；搖晃使當輪玩家下降一階。底層爆破會讓梯上的所有玩家落地。每人每 2 秒只能攻擊一次、說一句話。烏鴉約每 5～15 秒飛過一次，可能撞落當輪玩家一階。每輪先有 20 秒思考，接著顯示 10 秒倒數；逾時由遊戲規則選一張可出的牌和目標，該玩家累積 30 秒。累積逾時達 2 分鐘時全房公告並倒數 10 秒，接著該玩家退出，留下的玩家從第 1 局、0 分與新手牌重新開始；剩下不足 2 人則結束。任一仍在線的玩家可推進逾時倒數，無須依賴房主瀏覽器。神社背板每間房間隨機使用海浪、赤富士、櫻霞、松月或雲鶴風格，鳥居不變，並顯示各玩家總積分。這些互動只適用於神社版房間。

神社版本機備份與實作說明見 `versions/2026-09-25-shrine-v1-before-ladder-rework.zip` 和 `docs/shrine-wall-prototype.md`。

第二版立體塔已向木梯前側靠近；九種頭像改用更鮮明的顏色、表情與臉部彩繪，任務頭像也同步更新。遊戲中點自己的任務頭像會讓對應立體頭像只在自己的畫面閃爍兩秒。塔後方的順位標籤已移除，保留右側前三名標記。

本機後續版為九個不倒翁分別加入「勝、安、優、穩、活、平、日、月、喜」字樣與對應墨色。玩家可在大廳選九款不倒翁頭，角色移動塔時會伸手觸碰。角色頭頂只顯示姓名與所站順位；積分、姓名與聊天文字已提高對比與清晰度。
