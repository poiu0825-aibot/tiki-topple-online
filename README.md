# 推倒堤基 · Tiki Topple

以 Tiki Topple 為靈感的瀏覽器多人桌遊原型。boardgame.io 同步回合、玩家位置與房間；Three.js 呈現熱帶島嶼桌面、平面人頭圖騰與可行走的火柴人。地板圖騰和祕密卡使用同一份 SVG 圖案。

## 本機啟動

需要 Node.js 20 或更新版本。

```sh
npm install
npm start
```

開啟 `http://localhost:5173`。`npm start` 會同時啟動 Vite 網頁（5173）、boardgame.io 遊戲伺服器（8000）和 Socket.IO 聊天室（8001）。

房間狀態存在遊戲伺服器記憶體中，伺服器重新啟動後會清除。跨網路分享需要在前端建置時將 `VITE_GAME_SERVER`、`VITE_CHAT_SERVER` 設為公開伺服器網址，並在伺服器設定 `GAME_ORIGIN`。別人的瀏覽器無法連到你電腦上的 `localhost`。

區域網路遊玩時，可把 `GAME_ORIGIN` 設為房主電腦的網頁網址（例如 `http://192.168.1.20:5173`）；頁面會以相同主機名稱連到 8000、8001 埠。網際網路遊玩需將網頁和兩個服務部署到可公開連線的主機。

## 公開部署

`render.yaml` 會將前端、boardgame.io 遊戲伺服器與聊天室部署為同一個 Node.js Web Service。將此 repo 連到 Render 後建立 Blueprint，Render 會依設定建置網站並啟動服務。服務使用 HTTPS 與 WebSocket，房主可分享房間連結給朋友。

免費 Web Service 閒置 15 分鐘後會休眠，下一次連線可能需等待約一分鐘；服務重啟或休眠時，記憶體中的房間會清除。適合朋友測玩，不適合需要持續在線或保存房間資料的正式服務。

## 規則摘要

- 2–4 人一局，九座圖騰由前至後排列。每人抽取三座有高、中、低順位的祕密圖騰。Gamewright 原版每人雙人局 7 張、三至四人局 6 張動作牌；本站另加「互換」牌，分別為 8 張與 7 張。
- 每回合打出一張牌：Up 1／2／3 將圖騰向前移動；Topple 將任一圖騰推到隊尾；互換可交換任意兩座圖騰；Toast 爆破隊尾圖騰。每位玩家的首回合不能使用 Toast。
- 一局在只剩三座圖騰或所有人的手牌都出完時結束。最高順位祕密圖騰在第一名得 9 分；中順位在前兩名得 5 分；低順位在前三名得 2 分。
- 房主設定 1–60 分的整場目標，至少完成一局才判定勝負。顏色撞選時，玩家猜拳決定保留顏色者。

## 操作

- 建房後分享網址或配對碼；配對碼可在首頁搜尋。重新開啟房間連結時，瀏覽器會嘗試以本機保存的憑證回到原座位。
- 首次加入需設定 20 字以內的顯示名稱。WASD／方向鍵可行走，點地板可移動；拖曳可旋轉並調整視角高度，手機可用雙指縮放。出牌時伺服器依人物當下站立位置，選取最近且在操作距離內的圖騰；無須先點選目標。點地板圖騰仍可作為走路捷徑。「互換」的第一張依站立位置決定，第二張可從圖案列表任選。
- 點其他玩家會自動走過去推擠，對方會跌倒、位移並站起來。接近人頭時玩家頭上的名稱旁會顯示紅色順位數字。
- 九張平面人頭依順位在地板上排列，旁邊標有 1～9。Toast 爆破最後一張人頭，附近玩家會被炸飛；上方人頭及周圍短暫燻黑五秒。
- 祕密任務圖騰以約 75% 不透明度顯示在場景邊緣，可收合。聊天室文字與快捷對話都會在說話者頭上顯示約三秒的半透明泡泡。
- 圓盤上有橫式的玩家總積分板，手牌上方顯示目前排列的即時得分；四角座位姓名標籤已移除。快速對話按鈕位於場景右下角，計分規則與局數同列並可收合。
- 右上計分規則可收合；每局結束後玩家可各自選擇留下或回首頁，所有留下的人同意後會開始下一局。

## 專案結構

- `src/game.js`：boardgame.io 規則、局數與分數狀態。
- `src/main.jsx`：首頁、房間、玩家操作與聊天室。
- `src/TikiScene.jsx`：平面圖騰、火柴人、視角、行走與爆破動畫。
- `src/tikiArt.js`：地板圖騰與祕密卡共用的人頭 SVG。
- `src/layout.js`：圖騰順位位置、玩家起點與操作距離。
- `src/style.css`：響應式介面、牌組與提示動畫。
- `server/index.js`：boardgame.io 伺服器與 Socket.IO 聊天服務。
