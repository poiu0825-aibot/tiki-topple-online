# 立體不倒翁頭像塔試作

此試作保留為原版圓形場景旁的立體對照塔。原本的平面頭像、任務卡與遊戲規則均未替換。

## 本機資產

- Blender 原檔：`assets/source/daruma-tower-prototype.blend`
- 遊戲模型：`public/assets/daruma-tower-prototype.glb`
- Blender 預覽圖：`assets/preview/daruma-tower-blender.png`
- 建模步驟：`blender/build_daruma_tower.py`、`blender/add_daruma_insignia.py`、`blender/render_daruma_tower.py`
- 原版封存：`versions/2026-09-25-flat-game-before-3d-tower.zip`

九個模型使用與 `src/game.js` 相同的顏色與表情順序。輪廓取自使用者提供的 Tripo 展示影片：圓潤的不倒翁、白色臉框、黑色眉眼與金色「福」字；為 Blender 建立的可編輯試作，並非原影片模型的直接擷取。

## 場景行為

- 立體塔位於圓盤旁，與地板上的九張平面圖騰同步顯示同一排列。
- 按「近看立體對照塔」可把鏡頭轉向並拉近塔，按「回看圓盤」返回。
- 最上方三層顯示 1、2、3 的標記；正式得分仍由原遊戲規則計算。
- 地板末位圖騰被爆破時，對應的立體頭像縮小消失，其餘頭像平滑下降，底部同時出現火花。
- 在待開局畫面按「預覽底部爆破」可演示同樣的塔身動畫，約四秒後自動恢復；這個按鈕不改動遊戲棋盤或玩家狀態。
- 塔目前只供觀察，不接受選取或出牌。玩家仍以地板頭像與站立位置操作。

## 擺放建議

立塔適合作為主要視覺與順位提示。九層聳立能清楚表現上方三層計分，以及底部爆破後整塔下落；但在一般視角和手機尺寸下，每層臉會縮小。現階段保留地板平面頭像作操作介面、使用近看按鈕檢視立塔。待使用者確認造型與可讀性後，再決定是否逐步替換任務卡與地板排列。
